# Spartacus Community Expo prototype
This is an **initial Expo Go shell**, not the complete Coach app. It opens public WordPress content and WooCommerce pages. The Coach features, authentication, secure sync, offline behavior, and native navigation are not yet migrated.

Run on a computer with Node.js:
```sh
cd mobile
npm install
npx expo start --tunnel
```
Scan the QR code with Expo Go. No QR is available until a development server is running. Verify article routes, shop pages, checkout and language behavior on a real phone. Do not publish to app stores before QA.
